손그림의 모바일 기본 배열은 첫 줄1/2, 둘째 줄3/4, 셋째 줄5다. 2열에서 이름·가격이 읽히지 않는 폭은 1열로 내려도 되지만 **DOM/읽기 순서는 같아야 한다**. 쿠키 카드가 마지막 한 개라고 가격/크기를 과장하지 않는다.

**여기에 갸또컵케이크·브라우니컵케이크 카드는 없다.** 그렇다고 두 제품의 판매 코드·직접 상세·과거 주문을 삭제하지 않는다.

모찌 카드를 맛별 4개+세트로 증식하지 않는다. 고정4구·자유4구·원하는 수량 구매는 **같은 모찌 상세 안의 선택**이다. 세트 모드가 여러 개여도 카테고리 카드 수는4개다.

**스모어 카드는 이 카테고리에서 제거하되 판매 자체는 유지한다.** 기존 상세 주소에 접근해도 Celebrate에 속한 현재 상품을 보여줄 수 있다.

### 2.3 Celebrate — 3개

1. 갸또쇼콜라컵케이크.
2. 브라우니바스크컵케이크.

## 6. 쇼콜라모찌 — 6종, 4구 선물박스와 단품

2026-10-15 사용자 최신 확정: 모찌는 미배포 로컬 기능이다. Renewal v2를 유지하며 6종·gift-four/singles만 사용한다. 4구는 선택 단가 합산·박스 무료, 단품 선택 개별포장50c. 이전 모찌 장바구니는 별도 보관 후 재선택하며 실제 운영 케이크·초콜릿과 역사 reader는 보존한다.

- 단가: 딸기1000c, 청포도950c, 귤900c, 바나나900c, 앙버터850c, 생초콜릿800c. 공개 Chocolate 카드는 첫 번째 모찌 카드 하나이며 상세 경로는 유지한다. 최저 단품 가격은 AUD8.00.
- `gift-four`: 원하는 맛으로 정확히4개, 중복 허용. 단품 합산이며 할인 없음. 같은 구성 박스는 quantity만큼 반복하고 다른 구성은 별도 lineId로 보존한다. 박스 포장0c, 개별포장 중복선택 금지.
- `singles`: 6종 맛별 수량 합계1개 이상. quantity=1, 개별포장 선택 시 실물개수×50c. $100 면제·자동 박스·자동 할인 없음.
