공개 Git에는 명시적으로 검토한 소스·테스트·개발 문서만 포함한다. 폴더의 이전 문서·ZIP·reference 원본·mochi-launch-spec.md·비공개 레시피 사진·confirmed-decisions-20261014.md 원본 조사/제조 참고는 로컬 전용이며 ignore allowlist 밖이다. 삭제하지 않는다. 문서의 로컬 참고 이미지 경로는 원본 보존 위치를 기록한 것으로 공개 리포지토리에 이미지 첨부를 약속하지 않는다. 공개 상품 사진은 승인된 파베 하트통 이미지 한 개만 사용한다.

qa-price-fixtures-v0.7.json의 renewal_contract_cases는 순수 가격 테스트에서 실행한다. 문서 산술 사례 개수를 앱 테스트 통과 수로 보고하지 않는다. 기존 가격/사이즈/시간은 저장 스냅샷으로 보존한다.

실행 결과·변경 파일·미확인 운영 항목·향후 배포/롤백 순서는 implementation-progress.md를 참조한다. PUBLIC-SHA256SUMS.txt는 공개 개발 문서의 체크섬이며 로컬 원본 ZIP의 매니페스트를 대체하지 않는다.
