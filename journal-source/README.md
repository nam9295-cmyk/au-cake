# Approved Journal packages only

This public directory must contain **only content and photographs explicitly approved for public source and deployment**. `draft` and `noindex` do not make Git files private.

Keep working exports outside the repository. `npm run journal:prepare -- --input /absolute/export --expected-revision 0` writes only to the ignored local workspace. See [publishing instructions](../docs/journal-publishing.md) for the package contract and preview workflow.

The first reference package, `draft-01`, contains the owner-approved FigCraft article and three public WebP photographs. Its native design, other drafts and private preparation state remain outside public Git.
